# CodeAlpha_Hangman

A text-based Hangman game built for the CodeAlpha Python Programming Internship (Task 1).

## Features
- Random word chosen from a list of 5 predefined words
- Maximum of 6 incorrect guesses
- Input validation (single letters only, no repeated guesses)
- Play-again option

## How to Run
1. Install Python 3 from python.org
2. Download `hangman.py`
3. Open a terminal in the file's folder and run:
```
python hangman.py
```

## Concepts Used
`random`, `while` loop, `if-else`, strings, lists
